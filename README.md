# Universal Crew – 1.20.1 Forge v3

Mine Mine no Mi ile birlikte kullanılabilecek bağımsız bir tayfa yönetimi addon'u.

## v3
- **K** ile Crew menüsü.
- Tayfa adı + PNG logo.
- Menüden davet eşyası verme.
- Recruit edilen üyelerin isimleri ve durumları listelenir.
- Bir veya birden fazla üye seçilebilir.
- **ATAK:** kaptanın son vurduğu / kaptana son saldıran güvenli hedefe saldırırlar.
- **TAKİP ET:** takip moduna geçer; yolculuk araç/gemi üzerindeyse `stopRiding()` ile kalkıp kaptana gelir.
- **DUR:** hedefi bırakır ve olduğu yerde bekler.
- Aynı kaptana ait recruit'lar hedef olarak otomatik reddedilir; tayfa birbirine saldıramaz.
- Önceki sürümdeki basit sağ tık FOLLOW/IDLE sistemi kaldırıldı; yönetim artık K menüsünden yapılır.

## Derleme
Java 17 + Forge 1.20.1 (47.4.10) hedeflenir.
